# Security policy

## Supported versions

Security fixes are applied to the latest released version of Nux Exporter.

## Reporting a vulnerability

Do not disclose security vulnerabilities in public GitHub issues.

Use GitHub's private vulnerability reporting feature in the Nux Exporter repository. Include a description, reproduction steps, affected versions, and the potential impact.

Nux Exporter performs all processing locally and does not intentionally make network requests or collect telemetry.
