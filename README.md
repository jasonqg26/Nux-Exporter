# Nux Exporter

Nux Exporter is an Open Source Obsidian plugin intended to provide a clean, extensible foundation for exporting content from an Obsidian vault.

## Objective

The project will offer a maintainable export workflow while keeping its architecture modular and easy for contributors to extend.

## Current status

**MVP in development.** The repository currently contains only the initial plugin scaffold and build configuration; export features have not been implemented yet.

## Development

Requires Node.js 18+ and npm 9+.

```bash
npm install
npm run dev
```

Use `npm run build` to create the production `main.js` bundle, and `npm run check` to validate TypeScript types.
