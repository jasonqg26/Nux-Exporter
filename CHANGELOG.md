# Changelog

All notable changes to this project will be documented in this file.

## [0.1.1] - 2026-08-08

### Fixed

- Detect the active Obsidian configuration directory through `Vault.configDir` instead of assuming it is named `.obsidian`.

## [0.1.0] - 2026-08-08

### Added

- Complete-vault export from the command palette.
- Recursive folder export from the file explorer context menu.
- Default ignored-folder scanner with deterministic ordering.
- Frontmatter removal and Markdown normalization.
- Wikilink and embed conversion.
- Excalidraw text extraction without compressed drawing data.
- Hierarchical index with native Obsidian navigation.
- Export statistics and source metadata.
- Initial TypeScript and esbuild project structure.
